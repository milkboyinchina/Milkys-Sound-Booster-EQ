# Release v1.0.5 — 2026-10-18 (CI green, font-scale EQ, update checker)

## Summary
Restores a reliable green CI path and adds the first in-app update checker for
the three distribution channels. Also fixes the long-standing 1.5x/2.0x
font-scale clipping on the equalizer and preset action rows.

## Artifacts
- Release APK (GitHub/sideload): `.build-outputs/playstore/com.milkys.soundbooster-v1.0.5-release.apk`
- AAB (Play upload): `.build-outputs/playstore/com.milkys.soundbooster-v1.0.5-release.aab`
- Workflow: `.github/workflows/ci-cd.yml` tag build (`v1.0.5`)

## What changed
### Fixed
- CI screenshots no longer embed `GIT_SHA`/`BUILD_MOMENT`; visual baselines are deterministic across commits.
- Play Console references are tracked under `app/screenshots/`.
- Equalizer bands use responsive `FlowRow` columns (5/3/2) and preset actions wrap to 2 columns at ≥1.5x, keeping 48dp targets.
- `BUILD_TARGET`/`INCLUDE_GOOGLE_ADS` now honour exported env over `.env` so playstore/fdroid builds get the right channel.
- Jules action pinned to `v1.0.0`; CI-fix, issue-label, and weekly workflows now have secret guards and concurrency.

### Added
- Settings → About version checker:
  - Play Store target opens the Play Store listing.
  - GitHub target checks `releases/latest` and opens the release/APK.
  - F-Droid target checks `/api/v1/packages/<applicationId>` and opens the F-Droid page.
- `INTERNET` permission and corrected GitHub repository URL.
- `EqualizerFontScaleTest` matrix at 320dp for 1.0x/1.5x/2.0x, light/dark.

### Changed
- GitHub releases are tag-driven only; manual dispatch builds artifacts without creating a release.
- Actions bumped to current majors and jobs pinned to `ubuntu-24.04`.
- Pages publishing is gated behind the `ENABLE_PAGES` repository variable.
