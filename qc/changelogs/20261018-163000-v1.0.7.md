# Release v1.0.7 — 2026-10-18 (release pipeline fail-closed + assets)

## Summary
Fixes the last release-pipeline gap: Gradle failures were masked by `| tee`
because the scripts did not enable `pipefail`, so the job reported success with
an empty `.build-outputs/`. A clean checkout also had no `debug.keystore`, so
`validateSigningRelease` failed. The workflow now fails closed and generates an
ephemeral debug keystore when `KEYSTORE_BASE64` is absent.

## Fixed
- `scripts/build.sh` and `scripts/build_play_console_release.sh` now use
  `set -o pipefail`, so Gradle failures propagate through `tee`.
- Release workflow generates `debug.keystore` when `KEYSTORE_BASE64` is not
  configured, with a `Debug-signed release` warning.
- Added an explicit staging assertion: the job fails if no APK/AAB files are
  produced.
- `release-assets/` is now populated and attached to the GitHub Release.
