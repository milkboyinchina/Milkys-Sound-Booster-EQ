# Release v1.0.4 — 2026-10-12 (cold-start black-screen fix)

## Summary
Fixes the Play-review black screen on second launch (Vivo V1901K, Android 9,
Indonesian): infinite `onCreate` recreate loop from unconditional
`setApplicationLocales()` when a per-app language is persisted. Plus banner
single-`loadAd` cleanup and a Robolectric regression test.
