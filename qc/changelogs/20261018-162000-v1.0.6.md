# Release v1.0.6 — 2026-10-18 (release asset packaging fix)

## Summary
Fixes the tag release pipeline so APK/AAB files are actually attached to the
GitHub Release. The previous run created the `v1.0.5` release but uploaded no
assets because `.build-outputs/` is a hidden directory and the artifact/release
actions ignore hidden paths by default.

## Fix
- Added a `Stage Release Assets` step that copies every `.apk`/`.aab` from
  `.build-outputs/` into the visible `release-assets/` directory.
- `actions/upload-artifact` now uploads `release-assets/`.
- `softprops/action-gh-release` now attaches `release-assets/*.apk` and
  `release-assets/*.aab`.

## Verification
- `actionlint .github/workflows/*.yml` PASS.
- Tag run builds both the release APK and AAB.
- Release assets are visible in the GitHub Release UI and workflow artifact.

## Artifacts
- `release-assets/*.apk`
- `release-assets/*.aab`
- Workflow artifact: `android-release-outputs`
